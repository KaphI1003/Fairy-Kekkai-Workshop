# Fairy Kekkai Workshop ASS 适配功能增强版 · 3.1.0 EX

This package is a modified build of [Fairy Kekkai Workshop v3.1.0](https://github.com/Fairy-Oracle-Sanctuary/Fairy-Kekkai-Workshop/tree/v3.1.0). The fork adds RIFE interpolation, Real-ESRGAN super-resolution, OCR timing and ASS layout/style extraction, ASS translation and subtitle compositing. Changes in this build were prepared on 2026-11-19. The Workshop code and bundled Qt-Fluent-Widgets are distributed under GPLv3. The original Workshop icon by Fairy Oracle Sanctuary is distributed under CC BY-SA 4.0. The license texts are in the installed `licenses` folder.

The built-in tools cover local OCR, subtitle processing and transcription. RIFE and Real-ESRGAN require a supported Vulkan driver. CUDA OCR needs a compatible NVIDIA driver. Online providers require network access and their own credentials when applicable. Google Lens and Bilibili upload are unavailable in this build.

The standard installers omit the CC BY-NC 4.0 AniSD weights. CPU and CUDA 12.9 packages include the standard Real-ESRGAN and RIFE weights. The CUDA package also has a CPU OCR fallback.

Use the matching Workshop source archive alongside the installer. GitHub's generated source archives omit the contents of the Qt-Fluent-Widgets submodule. GitHub Release assets must be smaller than 2 GiB.

The source links above identify components. The release source index identifies the corresponding source, patches and scripts for the stand-alone FFmpeg build and the separate FFmpeg copies bundled by OpenCV and PyAV. The PyAV Windows recipe links x264 and x265 into its DLLs. The release provides the linked FFmpeg build under GPLv3 and preserves the original licenses of its source components. CUDA runtime files retain NVIDIA's own redistribution terms. The Workshop source archive covers this fork and its submodule.
